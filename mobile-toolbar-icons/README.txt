The Mortgage Geek — Mobile Toolbar Icons
=========================================

Four icons, two color variants each.

Icons:
  - calculator      (Calculator)
  - prequal         (Pre-Qual)
  - compare         (Compare)
  - cash-to-close   (Cash to Close)

Variants:
  - cream  — light icons on dark backgrounds (matches the live mobile toolbar)
  - navy   — dark icons on light backgrounds

Formats:
  - svg/  — vector, recommended for video editing (lossless at any scale)
  - png/  — 1024px raster, transparent background

Colors:
  - cream : #FAF7F2
  - navy  : #1B3A4B
  - gold  : #B8860B   (accent — always present)
